# TimeToGo — Handoff

A private iPhone app that gives a child (Sean) hourly bathroom reminders and lets
him answer **by voice** ("I went" / "snooze" / "stop") or one big tap — with daily
history and a reward loop so it feels like a game, not a chore.

- **Platform:** iOS 26+, SwiftUI + SwiftData, fully on-device (no backend).
- **Repo:** https://github.com/miteshs/timetogo (private, default branch `main`).
- **Status:** Builds, runs, and is installed on a real iPhone; all core flows work.
  Next real step is a live trial on Sean's phone.

---

## Status — what works
- Hourly reminders across a configurable window (default 3–11 PM) **plus** a 2:55 PM
  caregiver reminder, delivered by iOS even when the app is closed or force-quit.
- Tap **"I went now"**, or answer a reminder by **voice** or three big buttons
  (went / snooze / stop).
- Two on-device voice engines: Apple **SpeechAnalyzer** (default) and opt-in
  **WhisperKit** (better for atypical speech).
- Daily history + chart, a **goal ring**, **streaks**, a **confetti celebration**
  on each go, a **sticker collection** (Stickers tab), and a **Clear history** reset.
- Adaptive: a reminder due within 45 min of a logged go is automatically skipped.

## Quick start (Mac, Xcode 26.x)
The Makefile sets `DEVELOPER_DIR` automatically (xcode-select may still point at
CommandLineTools).

```
make verify-logic   # pure-logic checks — NO Xcode needed (53 checks)
make build          # build for the iPhone simulator
make test           # unit tests (Swift Testing) on the simulator
make run            # build + boot sim + install + launch
make device         # build (signed) for a connected iPhone
make generate       # regenerate TimeToGo.xcodeproj from project.yml (xcodegen)
```

The Xcode project is **generated by xcodegen from `project.yml`** and is gitignored —
edit `project.yml`, never the `.xcodeproj`. Voice can only be tested on a real
device (the simulator has no speech models; `ReminderView` has a typed-input test
mode there).

## Installing on an iPhone (free Apple ID)
Signing is a free Apple ID **"Personal Team"** (team `7LC9LFH33N`, baked into
`project.yml`). First time on a phone:
1. `make device` — builds + signs (`-allowProvisioningUpdates` auto-creates the profile).
2. `xcrun devicectl device install app --device <UDID> build/Build/Products/Debug-iphoneos/TimeToGo.app`
3. On the phone: **Developer Mode** — Settings → Privacy & Security (only appears
   after a dev install is attempted) → on → restart → "Turn On".
4. **Trust the cert** — Settings → General → VPN & Device Management → trust the
   "Apple Development" cert.
5. `xcrun devicectl device process launch --device <UDID> com.mpshah.timetogo`

Current test device: **Mitesh Phone** (iPhone 16 Pro), UDID
`2AF83E88-3B21-5FFC-A1DC-510A81E66E90`.

⚠️ **Free-build certs expire ~7 days after install** — the app stops launching until
you re-run `make device` + reinstall. Settings shows the "reinstall by" date.

## Architecture
- **Models** — `GoEvent` (SwiftData: went / snoozed / stopped / reminderFired);
  `AppSettings` (UserDefaults-backed `@Observable`: window, caregiver time, snooze,
  daily goal, child name, WhisperKit toggle, PIN, install date).
- **Scheduling** — `NotificationScheduler` schedules a **5-day rolling window of
  one-shot** local notifications (`daily.<epoch>` ids), re-armed on every launch and
  after each go. `skipNextReminderIfSoon()` re-arms while suppressing any reminder
  within 45 min after a go. (It is *not* a single repeating trigger — that's what
  makes a single occurrence skippable.) Snooze/test are separate one-shots.
- **Notifications** — `NotificationDelegate` uses the **completion-handler** delegate
  methods on the main actor (the `async` variant crashed on cold launch with
  "Call must be made on main thread"). Body tap opens the in-app reminder; action
  buttons handle in the background.
- **Voice** — `VoiceEngine` (`@MainActor @Observable`) captures via AVAudioEngine;
  two backends behind one surface:
  - Apple `SpeechAnalyzer` / `SpeechTranscriber` (default) — live results + endpointing.
  - **WhisperKit** (opt-in, `openai_whisper-small.en`) — 16 kHz capture, energy-VAD
    endpoint + 5 s cap, batch transcribe, strips non-speech annotations, prewarmed +
    statically cached. ~250 MB model downloads on first toggle-on; first inference
    after launch is cold (pre-load via the Settings toggle).
  - `IntentParser` (pure, unit-tested) → went / snooze(minutes) / stop, with personal
    variants (he says "I went" but the recognizer hears "ran"; also "done", "just did",
    "all set", …). Add new mispronunciations to `personalWentVariants`.
- **UI** — `RootView` TabView: Home / Stickers / History / Settings. Glassy iOS-26
  look via `GlassBackground` (shared gradient) + `.glassProminent`/`.glass` buttons +
  materials. `HomeView` (goal ring, streak, celebration), `RewardsView` +
  `StickerBook`, `ReminderView` (voice loop + big buttons), `HistoryView` (chart +
  per-day), `SettingsView`, `ConfettiView`, `Speaker` (spoken praise).

## Key decisions & constraints
- **Free Apple ID** (declined the $99 program): USB-cable install, ~7-day reinstall,
  **no TestFlight, no Critical Alerts**.
- **Time-Sensitive Notifications entitlement is disabled** — a Personal Team can't
  sign it, so reminders are ordinary notifications and **won't pierce Focus /
  Do-Not-Disturb / Sleep** (they still land silently in Notification Center).
  Re-enable on a paid account by uncommenting `CODE_SIGN_ENTITLEMENTS` in `project.yml`.
- This SDK has **no `glassEffect` view modifier** — only the Glass button styles;
  glass cards use materials.

## Known limitations
- Reminders are silenced during Focus/DND/Sleep (see entitlement note).
- WhisperKit's first transcription after launch is slow (cold CoreML) — pre-load it.
- The rolling reminder window covers ~5 days; if the app isn't opened that long it
  depletes — fine given daily use + the 7-day cert expiry.

## Debugging on device (what actually works here)
Crash `.ips` don't auto-sync; `log collect --device` needs root; `devicectl
sysdiagnose` errored. What works, no root: `brew install libimobiledevice`, then
`idevicecrashreport -e -k /tmp/crashes` (pull crash logs) and `idevicesyslog` (live
system log). A `.ips` is two JSON lines — parse `lastExceptionBacktrace` +
`usedImages` to symbolicate.
